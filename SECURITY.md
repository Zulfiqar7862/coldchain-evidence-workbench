# Security policy

This is an educational synthetic local workbench, not a clinically qualified or internet-hardened
service. Do not deploy it with real patient, product or customer data. See [the threat model](docs/threat-model.md).

Never post runtime credentials, private source documents, real identifiers or downloaded sensitive
bundles in public issues. Use the hosting provider's private vulnerability reporting when enabled;
otherwise contact the repository maintainer privately before disclosure. No private reporting channel
is claimed to be configured yet. No guaranteed security response SLA is advertised.
